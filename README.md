# PrepPulse — AI-Powered MCQ Test Generator & Practice Platform

PrepPulse is a modern, responsive Single Page Application (SPA) designed for practicing multiple-choice question (MCQ) exams using questions generated by AI models (such as ChatGPT, Claude, Gemini, DeepSeek, etc.).

---

## 🌟 Key Features

### 1. Test Configuration
- **Custom Topic & Subtopics**: Specify any topic or focus area (e.g. *JavaScript Closures*, *Kubernetes*, *Operating Systems*), with quick-select suggestions.
- **Dynamic Question Count & Timing**: Configure between 1 to 100 questions and time per question (in minutes).
- **Automatic Duration Calculation**: Changes to question count or time per question immediately calculate and update the total test duration.
- **Four Difficulty Levels**: *Easy*, *Medium*, *Hard*, and *Mixed* (balanced ~30% Easy, ~40% Medium, ~30% Hard).
- **Configurable Negative Marking**:
  - Full ON/OFF toggle switch.
  - Configurable penalty per incorrect answer (default 0.25 marks, with quick presets for 0.25, 0.33, 0.50).
  - Unanswered questions strictly receive 0 marks (no penalty).
- **Marks Configuration**: Customizable points per correct answer (default: 1) with live preview of the scoring rules.

### 2. Dynamic AI Prompt Generator
- Generates a strictly formatted prompt tailored to your exact configuration.
- Enforces an unambiguous JSON schema and instructs the AI to return raw JSON without Markdown code blocks or extraneous text.
- One-click copy with feedback notification and a download `.txt` option.
- Includes a step-by-step workflow guide.

### 3. JSON Import & Deep Validation System
- **Pasting & File Upload**: Large monospaced textarea and `.json` file uploader with drag-and-drop support.
- **Built-in Quick Sample Tests**: Instant 1-click loading for *JavaScript Core* and *Data Structures & Algorithms* tests to test immediately without opening an AI assistant.
- **Fault-Tolerant Parsing**: Automatically strips accidental Markdown code fences (` ```json `).
- **Granular Error Reporting**: Identifies problematic question IDs, duplicate IDs, missing options, invalid `correctAnswer` references, or missing explanations.
- **Test Preview Card**: Shows title, topic, question count, difficulty, and duration before launching.

### 4. Interactive Examination Interface
- **Sticky Test Header**:
  - Live countdown timer with warning styles and pulsating urgency when under 1 minute remains.
  - Real-time counters for answered, unanswered, and marked-for-review questions.
  - Quick access to "Submit Test".
- **Question Card**:
  - Highlighting for selected answers.
  - Mark for Review flag (toggles purple status).
  - Clear Answer button.
  - Previous and Next navigation.
  - Preserves selected answers across navigation.
  - Does **not** reveal answers or explanations during the test.
- **Interactive Question Palette**:
  - Grid of question numbers with 5 distinct visual states:
    1. *Not visited* (neutral slate)
    2. *Visited but unanswered* (amber)
    3. *Answered* (emerald green)
    4. *Marked for review* (purple)
    5. *Answered & marked for review* (purple with green indicator)
  - Color legend with live counters.
  - Collapsible drawer on mobile devices.
- **Safety & Persistence**:
  - Session persistence in `localStorage`: tab reload restores test state and adjusts remaining time accurately based on expiration timestamps.
  - Browser `beforeunload` warning to prevent accidental tab closing.
  - Automatic test submission when the timer reaches 00:00.
  - Submission modal displaying a summary of answered vs. unanswered questions.

### 5. Accurate Result Calculation & Performance Dashboard
- **Scoring Formula**:
  $$\text{Score} = (\text{Correct} \times \text{Marks}) - (\text{Incorrect} \times \text{Penalty})$$
  $$\text{Accuracy} = \frac{\text{Correct}}{\text{Attempted}} \times 100$$
- **Metrics Display**: Final score, maximum possible marks, percentage, accuracy (displays "N/A" if 0 attempted to prevent division-by-zero errors), time taken, and total negative penalty applied.
- **Celebratory Confetti**: Triggers celebratory effects on scoring $\ge 60\%$.
- **Detailed Question-by-Question Review**:
  - Visual status badges (*Correct*, *Incorrect*, *Not Attempted*).
  - Clear color differentiation: user's correct choice (green), user's incorrect choice (red), actual correct choice (green).
  - Comprehensive explanation cards explaining why the answer is correct.
  - Category filters: *All Questions*, *Correct*, *Incorrect*, *Unanswered*.
  - Global expand/collapse toggle for explanations.
- **Post-Test Actions**:
  - *Retake Test*: Fresh timer and reset answers on the same question set.
  - *Create Another Test*: Return to the configuration page.
  - *Review Mistakes*: Instant filter jump to incorrect and skipped questions.
  - *Copy Result Summary*: Formatted text summary copied to clipboard.
  - *Print / Save as PDF*: Print-optimized styling.

### 6. Design & Accessibility
- Clean typography with Google Fonts (*Plus Jakarta Sans* & *JetBrains Mono*).
- Light mode by default with Dark Mode toggle persisted in `localStorage`.
- Fully responsive across desktop, tablet, and mobile screens.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- `npm` (comes with Node.js)

### Installation

1. Navigate to the project directory:
   ```bash
   cd MCQ_Platform
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Development Server

Start the Vite development server:
```bash
npm run dev
```

Open your browser and navigate to:
```
http://localhost:5173/
```

### Running Automated Tests

Run the built-in unit test suite (testing prompt generation, JSON validation, and score calculation edge cases):
```bash
node test-runner.js
```

### Building for Production

Compile and bundle the production build:
```bash
npm run build
```

The compiled assets will be in the `dist/` directory, ready to be hosted on GitHub Pages, Vercel, Netlify, or any static web server.

## 📋 JSON Schema Example

When the AI generates questions, it returns the following JSON structure:

```json
{
  "title": "JavaScript Core & Modern ES6+ Assessment",
  "topic": "JavaScript",
  "difficulty": "Medium",
  "totalQuestions": 5,
  "timePerQuestionMinutes": 1,
  "totalDurationMinutes": 5,
  "marksPerCorrectAnswer": 1,
  "negativeMarking": {
    "enabled": true,
    "penaltyPerIncorrectAnswer": 0.25
  },
  "questions": [
    {
      "id": 1,
      "question": "Which of the following statements accurately characterizes the difference between let and var in modern JavaScript?",
      "options": [
        { "id": "A", "text": "var is block-scoped while let is function-scoped" },
        { "id": "B", "text": "let is block-scoped and subject to Temporal Dead Zone, while var is function-scoped and hoisted with undefined" },
        { "id": "C", "text": "let variables can be redeclared within the exact same scope without throwing an error" },
        { "id": "D", "text": "var creates immutable bindings while let allows reassignment" }
      ],
      "correctAnswer": "B",
      "explanation": "let variables are block-scoped and remain in a Temporal Dead Zone until initialized. var is function-scoped and hoisted with undefined."
    }
  ]
}
```
